How to use the Firmware Editor

This editor works just like the Arduino IDE but directly in your browser:

  • Modify Code: Select main.cpp to edit the core Bad Apple video player logic.
  • Save: Press Ctrl+S or the Save button to save changes to the server.
  • Verify (Compile): Click the ✔ button top-left to compile the firmware for the selected board environment.
  • Flash: After compilation is successful, go back to the main page to flash the new firmware to your ESP32 over USB!

Note: Since it compiles on your local server, the first compilation might take a minute as it downloads the PlatformIO toolchain.
